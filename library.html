Duplicate matching

A row is a duplicate when every column matches a row already in the library. Columns listed here are left out of that comparison, so an export stamp that changes daily doesn’t make old rows look new.

Leave a real data column out of the comparison and two rows that differ only in that column will collapse into one. Add only columns that describe the download itself.

Changing this affects rows collected from now on. Rows already in the library keep the fingerprint they were stored under.
